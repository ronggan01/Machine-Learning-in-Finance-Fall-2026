# Cross-Validation with Credit Card Default Dataset

This folder contains my homework of the Machine Learning in Finance course at the University of Illinois Urbana-Champaign.

This project evaluates a decision tree model using the Credit Card Default dataset. The analysis compares two cross-validation approaches: Monte Carlo Cross Validation and 10-fold Stratified Cross-Validation. The model's performance is also evaluated on a separate 10% holdout test set.

## Methods

The analysis includes:

* Stratified 90/10 train-test split
* Monte Carlo Cross Validation using repeated random train-test splits
* 10-fold Stratified Cross-Validation
* Comparison of cross-validation estimates with holdout test performance
