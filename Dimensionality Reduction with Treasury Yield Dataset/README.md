# Treasury Yield Data with Dimensionality Reduction

This folder contains my homework for the Machine Learning in Finance course at the University of Illinois Urbana-Champaign.

This project analyzes a dataset with 30 predictor attributes and the target variable `Adj_Close`. The analysis compares Linear Regression and Support Vector Regression (SVR) using both the original predictor attributes and a three-component PCA representation.

## Methods

The analysis includes:

* Exploratory Data Analysis
* Principal Component Analysis (PCA)
* Linear Regression using the original 30 attributes
* Linear Regression using 3 PCA components
* SVR using the original 30 attributes
* SVR using 3 PCA components
* Comparison of model performance and training time
