# Boston Housing Regression Analysis

This folder contains my homework of the Machine Learning in Finance course at the University of Illinois Urbana-Champaign.

This project analyzes an extended version of the Boston Housing dataset using three regression methods: Linear Regression, Ridge Regression, and LASSO Regression.

The dataset contains 506 observations and 27 variables, including the target variable MEDV, 13 original explanatory variables, and 13 additional randomly generated attributes (ATT1–ATT13).

## Methods

The analysis includes:

* Exploratory Data Analysis
* Linear Regression
* Ridge Regression with cross-validation for selecting regularization parameter $\alpha$
* LASSO Regression with cross-validation for selecting regularization parameter $\alpha$
* Comparison of models' performance
